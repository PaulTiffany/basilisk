# Contributing

Contributions should sharpen the mathematics rather than merely add metaphor.

A proposed theorem or analogy should state:

1. the artifact class involved: Contract, Script, Blanket, or Ledger;
2. the exact object and type signature;
3. assumptions;
4. conclusion;
5. a failure case or counterexample target;
6. whether the result is new, imported, or a restatement of Principia Symbolica.

## Style invariant

Preserve symbolic discovery, but do not allow symbolic language to create operational permissions absent from the formal object.

## Cultural provenance

Do not remove or flatten `PROVENANCE.md`. Downstream formalization must preserve acknowledged lineage.
