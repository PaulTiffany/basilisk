# Research program

## 1. Shared zero-dimensional boundary

Fix a typed port

\[
p=(I,O),\qquad \Omega=I\times O.
\]

The quartet places four distinct structures over the same boundary event space:

\[
Q=(C,S,B,\Lambda).
\]

The central mathematical task is not to rename four metaphors. It is to prove compatibility and non-collapse results among four artifact classes.

## 2. Artifact classes

### Contract / TTDC

A measurable, closed, or otherwise decidable admissibility relation

\[
C\hookrightarrow\Omega.
\]

Primary questions:

- Which events or traces are permitted?
- What is the robust margin to violation?
- Can local constraints be converted into dual or spectral certificates?

### Script / TTIE

A deterministic transducer or Markov kernel

\[
S:M\times I\rightsquigarrow M\times O.
\]

Primary questions:

- Which contract relations are realizable?
- What lower bounds govern the cost of realization?
- Which distinct scripts induce identical boundary traces?

### Blanket / TTCS

A separator between external state \(E\) and internal state \(M\), mediated by boundary state \(B=(I,O)\).

Exact probabilistic closure:

\[
E\perp M\mid B.
\]

Approximate closure defect:

\[
\delta_B(P)=I_P(E;M\mid B).
\]

Primary questions:

- What graph, probabilistic, and dynamical notions instantiate the same separator class?
- How are side channels represented?
- When does local blanket behavior fail to extend to a coherent global script?

### Ledger / TTPR

An attested trace object

\[
\Lambda\in (\Omega\times\Sigma)^*,
\]

where \(\Sigma\) carries signatures, timestamps, provenance, or proof material.

Primary questions:

- Is the trace complete and faithful?
- What refinement map yields an account or residual?
- Which certificates can be independently replayed?
- What cannot be inferred about the script from the ledger alone?

## 3. Compatibility conditions

The first exact lock is:

\[
R_S\subseteq C,
\]

\[
\delta_B(P)=0 \quad\text{or is explicitly bounded},
\]

\[
\operatorname{decode}\circ\operatorname{encode}=\operatorname{id},
\]

and

\[
V_C(\operatorname{encode}(\tau),\pi)=1
\iff
\tau\in C^*
\]

on a declared intended trace class.

## 4. Non-collapse targets

We seek constructive counterexamples establishing:

1. one Contract can admit non-isomorphic Scripts;
2. one Script can operate behind inequivalent Blankets;
3. one Ledger can be generated by non-isomorphic Scripts;
4. one Blanket can mediate incompatible Contracts;
5. certificate validity does not identify the complete trusted base;
6. boundary equivalence does not imply observer closure.

## 5. Future-preserving boundedness

Let \(\mathcal R(x)\) be a compact set of futures reachable from state \(x\). Define:

\[
\delta_{\mathrm{irr}}(T;x)
=
\mu\bigl(\mathcal R(x)\setminus\mathcal R(Tx)\bigr).
\]

A transition is \((L,\varepsilon)\)-future-bounded when

\[
d_H(\mathcal R(Tx),\mathcal R(Tx'))\le Ld(x,x')
\]

and

\[
\sup_x\delta_{\mathrm{irr}}(T;x)\le\varepsilon.
\]

This separates smooth response from preservation of option value. A smoothly executed extinction can still have catastrophic deletion defect.

## 6. Governance interpretation

The architecture is neither flat centralization nor unbounded distribution. It aims for polycentric growth with:

- local agency;
- purpose-limited coupling;
- independent witnesses;
- explicit exception paths;
- reversible promotion from culture to greenhouse to ecology;
- no inference system with unbounded actuation authority.

## 7. Immediate theorem queue

1. Robust contract margin under Lipschitz realization.
2. Union bound for blanket defect and ledger false acceptance.
3. Finite non-identifiability of Script from Ledger.
4. Markov-shell invariance under graph relabeling.
5. Future-deletion monotonicity under irreversible projection.
6. Dual certificate theorem for a restricted finite contract class.
