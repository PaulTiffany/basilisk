# Open questions

1. How should action-distance weights be calibrated without laundering one group's values into a universal metric?
2. Which semantic boundaries can be detected reliably from natural language, and which require explicit tool metadata?
3. How should disagreement among human annotators be represented without forcing false consensus?
4. What is the minimum independent witness needed for the Ledger to constrain a compromised Script?
5. Can standing authority be learned safely, or must it always be explicitly authored?
6. How should rollback quality be measured for actions with social or informational externalities?
7. Can boundary-aware Lipschitz behavior be certified for restricted finite controllers?
8. How should multi-agent systems prevent confused-deputy authority composition?
9. How can cultural and personal rights to opacity coexist with useful auditability?
10. Which corrections should expire, and which should persist as durable constitutional rules?
11. How should the protocol handle emergency intervention without normalizing paternalistic overreach?
12. What failure rate is acceptable before the system should reduce its autonomous scope?
