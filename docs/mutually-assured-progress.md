# Mutually Assured Progress

MAP is a two-sided control objective:

- the model is not granted uncontrolled authority;
- the human is not burdened with a confirmation ritual for every trivial step;
- both preserve inspection, correction, pause, redirect, rollback, and continuation.

## Failure extremes

### Unbounded autonomy

\[
\text{initiative}-\text{authority bounds}-\text{witness}
\longrightarrow
\text{permission creep and hidden externality}.
\]

### Confirmation paralysis

\[
\text{checkpoint at every substep}
\longrightarrow
\text{blind approval, abandonment, or de facto delegation}.
\]

## MAP region

The desired region is:

\[
\boxed{
\text{reversible initiative}
+\text{semantic checkpoints}
+\text{inspectable witness}
+\text{local correction}
}
\]

Progress is “mutually assured” only in the modest operational sense that neither party must surrender the correction channel for useful work to continue. The phrase does not imply equal capabilities, equal responsibility, or guaranteed benefit.
